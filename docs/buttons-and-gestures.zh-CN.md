## 先看懂面板与选择

Twig 保留左、右两个面板。默认竖屏显示一个，横屏同时显示两个；可以在设置中固定单面板或双面板。单面板时，另一个面板仍保留自己的目录和展开状态。

| 名称 | 表示什么 | 与按钮的关系 |
|---|---|---|
| 当前面板 | 你正在操作的一侧；双面板下点哪一侧，哪一侧就成为当前面板。 | 大多数文件操作从这一侧取源文件。 |
| 当前目录 | 路径栏所指的位置，通常是树中高亮的目录。 | 「新建」在这里创建；复制、移动和压缩通常以对侧的当前目录为目标。 |
| 勾选项 | 通过复选框选中的文件或文件夹。 | 复制、移动、压缩、改名、删除和属性优先作用于勾选项；没有勾选时通常使用当前高亮项。根节点会受到额外保护。 |
| 对侧面板 | 当前面板的另一侧，即使暂时没有显示。 | 提供复制、移动、压缩的默认目标；「对比」使用左右两侧的当前目录。 |

文件夹是在树中**就地展开和收起**的。展开子目录后，父目录和其他已展开分支可以继续留在列表里。确认目标位置时看路径栏，不要仅凭屏幕上可见的文件名判断。

## 标题栏与面板切换

标题栏隐藏时，终端、音乐、切换和菜单移到操作栏上方的固定区域。下表中的长按功能在对应的两个位置都可使用。

| <img src="img/buttons/ic_terminal.svg" width="32" alt="终端"> 终端 | 返回已有终端会话；没有会话时创建本地终端。 | 在当前目录打开终端：本地目录使用本地 shell，SFTP 目录使用远程 shell。其他来源不支持此定位操作。 |
| <img src="img/buttons/ic_music_note.svg" width="32" alt="音乐"> 音乐 | 打开音乐播放器；不会仅因打开页面而启动原本暂停的播放。 | 打开播放器并开始或恢复播放；需要已有或可恢复的播放队列。 |
| <img src="img/buttons/ic_pane_to_right.svg" width="32" alt="切换到右面板"> <img src="img/buttons/ic_pane_to_left.svg" width="32" alt="切换到左面板"> 切换 | 激活另一个面板，箭头表示切换方向。 | 在另一面板打开当前目录，并切换过去。方便让两侧从同一位置开始浏览。 |

主菜单提供「设置」「视图」「缩略图」「记住位置」「全屏」「根节点设置」「操作栏」「主题」「锁定」和「退出」等入口。「锁定」仅在设置了主密码后出现。

**返回、锁定、退出的区别：**普通返回遵循设置中的返回键行为；返回键触发退出时始终确认。「锁定」要求再次解锁，但保留音乐、终端和共享。「退出」会停止音乐、关闭终端、停止共享并取消正在执行的传输。长按菜单属于退出操作。

## 文件操作栏速查

操作栏可滚动，默认竖屏一列、横屏两列。通过 **菜单 → 操作栏** 可以调整顺序及显隐。「创建副本」「属性」「退出」默认隐藏。

「—」表示没有单独的长按快捷操作。按钮受文件来源和当前状态限制，详见[按钮不见了或点不动](#按钮不见了或点不动)。

| <img src="img/buttons/ic_sort.svg" width="32" alt="排序"> 排序 | 打开排序设置，先显示默认设置。 | 打开排序设置，直接选中「所选目录」。 |

| <img src="img/buttons/ic_new_folder.svg" width="32" alt="新建"> 新建 | 在当前目录新建文件夹。 | 在当前目录新建文本文件。 |

| 位置 / 图标 | 操作 | 效果 |
|---|---|---|
| 路径栏 | 点击 | 在紧凑路径和横向滚动的路径按钮之间切换。 |
| 路径栏、来源图标或展开的路径按钮 | 长按或双击 | 编辑路径，直接跳转；restic 位置打开专用位置对话框。路径栏需可见且当前位置支持编辑，共用此路径栏的选择器也支持。 |
| 展开的路径按钮 | 点击某一级 | 选中该目录，显示直接子项并收起它的子目录；祖先保持展开。 |
| 路径栏来源图标 | 点击 | 收起或展开路径按钮。 |
| 文件夹行 / 图标 / 展开箭头 | 点击 | 通常在当前位置展开或收起目录；启用「点击行选择」且已有勾选项时，普通文件夹行改为勾选，图标和箭头仍用于展开或收起。已确认的空目录可能没有箭头。 |
| 文件行或图标 | 点击 | 通常打开文件；启用「点击行选择」且已有勾选项时，点击行改为勾选，图标仍用于打开。 |
| 文件或文件夹 | 长按 | 打开该项目的操作菜单，可按来源提供打开方式、分享、收藏、复制、属性等操作。 |
| 复选框 | 点击 | 勾选或取消勾选。列表中已展开且有子项的目录会循环：选目录本身 → 选直接子项 → 清空选择。 |
| 复选框 | 长按 | 从上次勾选或取消勾选的位置，到此项连续执行相同操作；两端必须属于同一目录、同一层级和同一树分支。 |
| 文件行最左侧的透明区域 | 点击 / 长按 | 点击展开或收起该行属性；长按打开第二个标签页。位置见下方[隐藏属性按钮说明](#文件行左侧的隐藏属性按钮)。 |
| 「收藏」或「网站」标题 | 长按 | 进入排序，用拖动把手调整顺序；点把手外或按返回结束，滚动不会退出排序。 |

### 点击行选择

入口是 **菜单 → 设置 → 点击行选择**，默认关闭。它让批量选择时可以点击较大的文件行区域，不必每次对准右侧勾选框。

| 状态 | 点击文件行的名称或文字区域 |
|---|---|
| 设置关闭 | 打开文件或展开、收起文件夹；通过勾选框选择。 |
| 设置开启，但当前没有勾选项 | 仍然打开文件或展开、收起文件夹。先用勾选框选择第一项。 |
| 设置开启，且当前已有勾选项 | 对普通文件和文件夹执行勾选或取消勾选。取消最后一项后，点击行恢复打开或展开行为。 |

**文件图标或缩略图仍用于打开，文件夹图标和展开箭头仍用于展开或收起。**左侧隐藏属性按钮、右侧勾选框和长按菜单也保留各自作用。以上行选择行为适用于列表和网格；根节点不参与普通文件的多选。

例如：先勾选 `a.txt`，再点击 `b.txt` 的名称区域，就会选中 `b.txt`；点击它的图标则打开文件。多选限于同一目录，选择另一目录的项目会清除原先的选择。

### 文件行左侧的隐藏属性按钮

**文件行左侧看起来空白的地方，也有一个属性按钮。**它平时透明、不显示图标，按下时才有圆形触摸反馈。

| 显示方式 | 去哪里点 |
|---|---|
| 列表 | 对准目标文件或文件夹所在行，点击**紧贴面板左边缘的窄条区域**。按钮覆盖该行高度，不随树的层级缩进向右移动；深层目录中通常就是图标左边的留白。 |
| 网格 | 点击该文件**缩略图的左上角**。右上角是勾选框，两者作用不同。 |

- **点击**：在该行下方展开属性卡片，再次点击收起。可以同时展开多个文件的属性。
- **长按**：直接展开属性并切换到第二个标签页；已有卡片时也会切换。标签内容依文件类型而定，只有一个标签时留在唯一的标签页。
- **作用对象**：始终是你点击的那一行，即使已勾选其他文件。要看整批勾选项的汇总属性，使用操作栏里的「属性」。

这里没有常驻的 ⓘ 图标；操作栏里的「属性」才使用该图标。网站书签和分组标题不提供普通文件的这个隐藏属性入口。

排序和视图独立设置：例如某目录按大小排序，同时保持列表显示。目录自己的设置优先，其次是最近的启用递归设置的祖先，最后才是全局默认。重置排序不会重置视图，反之亦然。

## 常用操作示例

### 把文件复制到另一个目录

1. 在一侧打开目标目录；用「切换」回到源目录所在面板。
2. 勾选要复制的文件，点击「复制」。
3. 检查目标路径。需要换位置时选择目标目录；双面板下也可在对侧浏览后确认。
4. 确认开始，查看进度。熟悉目标后，可长按「复制」直接开始。

「移动」使用相同的目标选择方式，完成后会删除源文件。「创建副本」始终在源文件所在目录生成另一份，适合先留一个可编辑副本。

### 打包并保留源文件

勾选文件，点击「压缩」，选择 ZIP 或 7z，检查保存位置并保持移动模式关闭。需要密码时在此设置；7z 加密还可隐藏文件名。长按快捷打包不设密码，也不删除源文件。

### 删除后找回来

删除时确认使用回收站，再从树中的回收站入口恢复。远程来源等不支持回收的项目会直接删除；不要把「删除」理解为总能撤销。长按删除只有在整批均可回收时才省略确认。

### 只改变一个目录的排序

先选中该目录，长按「排序」，在「所选目录」启用自定义排序。只想影响当前目录就不开递归；希望子目录继承时再启用递归。列表/网格从主菜单「视图」单独设置。

### 与电脑交换文件

在要共享的目录点击「共享」，检查只读、认证等选项后启动，在电脑浏览器输入显示的地址，也可用 WebDAV 客户端连接。之后可长按「共享」快速停止或重新启动；重新启动会沿用保存的选项，并优先使用当前目录。

## 视频播放器

在文件列表打开视频后，点击画面可显示或隐藏标题栏和底部控制栏；播放时控制栏会自动隐藏。按钮可能因屏幕宽度分成两行，图标和作用不变。

### 视频画面手势

| 手势 | 效果 |
|---|---|
| 单击画面 | 显示／隐藏控制栏。 |
| 双击画面 | 播放／暂停，画面左、右两侧作用相同。 |
| 按住正在播放的画面约半秒 | 临时加速，松手恢复之前的速度。可在「设置 → 视频播放」选择长按加速倍率。 |

### 剧集、片头片尾与播放记忆

上一集、下一集和片头片尾按钮要求已识别出至少两集的剧集队列。媒体服务器优先使用服务端提供的剧集顺序，普通目录则按文件名中的剧集编号分组；任意两个视频不一定会被识别成剧集。

设置跳过片头的方法：播放到正片开始处，点击「跳过片头」。设置片尾则播放到片尾开始处，点击「跳过片尾」。按钮会高亮，进度条显示标记；再次点击对应按钮可清除。**记录标记不会立即改变当前播放位置**，设置按同一部剧保存。后续播放会跳过已记录的片头；进入已记录的片尾时结束本集并切换下一集，最后一集则关闭播放器。已设置片尾的跳转独立于「自动播放下一集」开关。

「设置 → 视频播放」还提供：

- **自动播放下一集**：控制正常播完后的自动连播。
- **播放进度记忆**：控制普通文件的续播；媒体服务器还可提供自己的进度。「历史 → 继续观看」可再次打开未看完的视频。
- **记住音轨、字幕与画面缩放**：沿用你手动选择的选项，作用于同一文件或同一部剧；其他集没有匹配音轨或字幕时，不保证能恢复该选择。
- **打开视频时关闭音轨**：默认关闭。开启后，每次打开视频或新一集先关闭声音，仍可用音轨按钮手动恢复；不影响纯音频播放。
- **字幕样式、长按加速倍率**等选项。文本字幕样式不改变 PGS 等图片字幕的字体。

### 图片手势与缩放

| 手势 | 效果 |
|---|---|
| 双击图片 | 循环切换 **完整显示 → 铺满裁切 → 原始像素 → 完整显示**。完整显示保留整张图片；铺满时一部分可能超出屏幕；原始像素按 1:1 查看，超出部分可拖动。 |
| 双击后第二下按住，上下拖动 | 单指连续缩放，松手结束；不会因此触发长按菜单。 |

各模式大小相同时，切换可能看不出变化。裁切只是显示方式，不修改原文件。

## 图片对比

双击任一侧图片，循环切换 **原尺寸且不超出面板 → 完整适配面板 → 原始像素 → 初始模式**。初始模式仅缩小大图，不放大小图；完整适配可能放大小图；原始像素为 1:1。各模式大小相同时，切换可能看不出变化。

也可双击后第二下按住并上下拖动，进行单指连续缩放，松手结束，不触发长按菜单。开启同步时，另一侧跟随视口变化。

## 网站

双击内置浏览器的**网站内容区域**，可以隐藏或显示网站工具栏。网站配置中需开启「显示与工具栏 → 双击隐藏/显示工具栏」，新配置默认开启，也可通过网站默认配置调整。

该手势只切换工具栏，状态栏和导航栏由各自选项控制。页面元素检查模式优先处理元素选取。

启用此选项后，第二次点击由 Twig 接管。若希望使用网页原有的双击选词、缩放等行为，可关闭该选项；关闭后的具体行为取决于 WebView 和页面本身。

## 按钮不见了或点不动

| 现象 | 检查什么 |
|---|---|
| 找不到某个操作栏按钮 | 先滚动操作栏，再查看「菜单 → 操作栏」的显隐设置。创建副本、属性和退出默认隐藏。 |
| 找不到终端、音乐或切换 | 标题栏隐藏时，它们移到操作栏上方固定区。 |
| 文件操作变灰或部分菜单缺项 | 检查是否有可操作项，以及来源是否只读、目录是否可写、是否正在选择传输目标。压缩包和媒体服务器等来源能力不同。 |
| 长按复制没有直接开始 | 检查对侧面板是否已经选定有效、可写的目标；目标不合适时仍会要求选择或确认。 |
| 长按删除仍弹确认 | 回收站未开启，或选择中至少有一项不能回收。 |
| 长按搜索却打开网页 | 这是搜索引擎快捷入口；文件名搜索使用普通点击。可在「网站」标题菜单中配置搜索引擎。 |
| 找不到路径栏 | 检查是否启用了单面板隐藏路径栏，或将路径栏放到了底部。 |
| 横竖屏按钮位置不同 | 布局随方向、单/双面板设置及标题栏显隐变化。操作含义保持一致，以图标和名称查找。 |
