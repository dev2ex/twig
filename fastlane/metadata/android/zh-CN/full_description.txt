Twig 是一个对标 X-plore 的 Android 双面板文件管理器,原生 Kotlin + XML View 写成,不引 Material 库,依赖尽量少。

<b>一棵树,所有来源</b>

本地存储、压缩包、FTP、SFTP、SMB、WebDAV、S3、restic 备份仓库、Jellyfin/Emby 服务器,在界面看来都是同一种东西。任意两者之间的复制走的是同一条代码路径:SMB 上的目录可以直接压成本地 ZIP,远程压缩包里的文件可以流式传给 FTP 服务器。压缩包就地展开,和目录一样。

<b>体积优先</b>

按设备下载约 6.7 MB —— 这还包含一个 FFmpeg 音频解码器、一套 SMB 实现和一个视频播放器。加依赖前先算它在 APK 上的增量;WebDAV、S3 请求签名、git、restic 解密全是手写的,而不是引一个 SDK 进来。

<b>功能</b>

<ul>
<li>双面板各自独立导航,树式就地展开,网格视图与缩略图</li>
<li>任意两个来源之间复制、移动、改名、删除,带进度与取消</li>
<li>ZIP 与 7z 的读写,含加密包</li>
<li>任意两个来源之间的目录对比与同步</li>
<li>占用图(treemap),双指缩放</li>
<li>内置查看器:带语法着色且可编辑的文本、十六进制、图片、视频与音频</li>
<li>手写的 git 客户端:状态、历史、双栏 diff、worktree 与子模块,本地与远程仓库都支持</li>
<li>SSH 终端,支持多会话,另有本地 shell</li>
<li>WiFi 共享:Twig 变成 HTTP 与 WebDAV 服务器,电脑可以直接挂载</li>
<li>经 root 或 Shizuku 的特权访问 —— 是本地文件系统的回落,不是另起一棵树</li>
</ul>

<b>不太常见的几项</b>

<ul>
<li>只读浏览 restic 备份仓库,在设备上解密,快照按日期显示成目录。</li>
<li>网络共享上的视频不下载整个文件也能出缩略图:自己解析容器,定位到十分之一时长处的关键帧,只取约 2 MB。</li>
<li>蓝光 M2TS 播放,含 BDAV 的 192 字节包、DTS-HD Master Audio、经内嵌 AC-3 核心的 TrueHD,以及 PGS 位图字幕。</li>
<li>Jellyfin 与 Emby 的媒体库和别的来源一样浏览,播放进度同步回服务器,海报、标签、歌词、外挂字幕都取自 API,而不是去读媒体文件本身。</li>
</ul>

<b>关于这个版本</b>

F-Droid 上的是 <i>libre</i> 版,完全是自由软件,<b>不含 RAR 支持</b>:Android 上唯一堪用的 RAR 库是 UnRAR 许可证,它带使用限制,不满足自由软件的定义。除此之外与开发者自己发布的版本完全一致。

Twig 没有广告、没有统计、没有遥测,只在你自己配置的连接上使用网络。
