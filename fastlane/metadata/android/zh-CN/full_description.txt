Twig 是一个把所有存储来源装进同一棵树的 Android 双面板文件管理器,原生 Kotlin + XML View 写成,不引 Material 库,依赖尽量少。

<b>一棵树,所有来源</b>

本地存储、压缩包、FTP、SFTP、SMB、WebDAV、S3、restic 备份仓库、Jellyfin/Emby 服务器,在界面看来都是同一种东西。任意两者之间的复制走的是同一条代码路径:SMB 上的目录可以直接压成本地 ZIP,远程压缩包里的文件可以流式传给 FTP 服务器。压缩包就地展开,和目录一样。

<b>体积小，资源友好</b>

1.16.0 libre APK 实测为 10.45 MiB，同时包含 arm64-v8a 与 x86_64、终端及媒体播放器。新增依赖前先测量 APK 增量。

<b>功能</b>

<ul>
<li>双面板各自独立导航及根项目显隐，树式就地展开、缩略图；每个目录可单独设置排序与列表/网格视图，并可应用到子目录</li>
<li>跨来源复制、移动与删除，支持后台进度及取消；本地回收站支持批量恢复与清理；支持多文件分享及选中项属性；通过双面板选择器保存分享的文件或文本</li>
<li>批量重命名，支持文本或正则替换、编号和实时预览；名称输入弹窗自动弹出键盘并选中名称，文件保留扩展名</li>
<li>读取和创建 ZIP/7z，支持加密包并记住上次格式选择；浏览 tar 与 gz/xz/bz2/zst 文件</li>
<li>任意两个来源之间的目录对比与同步</li>
<li>占用图（treemap），双指缩放；可选底部工具栏、返回键退出、完成振动及前台完成通知</li>
<li>私有空间不纳入系统备份或配置导出，文件随应用卸载而删除</li>
<li>带语法着色、保留原编码的文本编辑，以及十六进制、PDF、图片和媒体查看器</li>
<li>音乐跨来源播放列表、波形定位、同步歌词与后台播放；封面上下滑动调音量，通知支持播放计时和退出</li>
<li>手写的 git 客户端:状态、历史、双栏 diff、worktree 与子模块,本地与远程仓库都支持</li>
<li>本地、SSH 与特权终端，支持多会话和闲置调暗；可将 shell 当前目录定位回文件树</li>
<li>可配置的文件、目录、网站与命令快捷方式；长按或双击路径栏可编辑路径</li>
<li>WiFi 共享:Twig 变成 HTTP 与 WebDAV 服务器,电脑可以直接挂载</li>
<li>网站书签与桌面快捷方式,支持每站显示设置、自定义 JavaScript/CSS、隐藏元素、手动资源拦截和网页调试</li>
<li>网站下载默认保存到 Downloads/twig;可选后台运行,通过带通知的前台服务维持会话</li>
<li>本地树内的 root/Shizuku 特权访问；系统允许时，通过保存的 SAF 授权访问 Android/data</li>
<li>保存凭据加密、主密码应用锁、指纹解锁与配置备份</li>
</ul>

<b>不太常见的几项</b>

<ul>
<li>只读浏览 restic 备份仓库，在设备上解密，快照按日期显示成目录。</li>
<li>对识别为同一系列且至少包含两集的视频，记忆并共用片头片尾跳过标记；不要求集数编号连续。</li>
<li>网络 MP4/MKV 缩略图通过容器索引定位关键帧，只需读取少量元数据和帧数据即可生成。</li>
<li>蓝光 M2TS 播放,含 BDAV 的 192 字节包、DTS-HD Master Audio、经内嵌 AC-3 核心的 TrueHD,以及 PGS 位图字幕。</li>
<li>Jellyfin 与 Emby 的媒体库和别的来源一样浏览,播放进度同步回服务器,海报、标签、歌词、外挂字幕都取自 API,而不是去读媒体文件本身。</li>
</ul>

<b>关于这个版本</b>

F-Droid 分发完全由自由软件组成的 <i>libre</i> 版，排除了采用 UnRAR 许可证、带有非自由使用限制的 junrar，因此<b>不含 RAR 支持</b>。开发者发布的 <i>full</i> 版增加只读 RAR 支持，其余功能相同。

Twig 本身没有广告、没有统计、没有遥测。网络访问由你的操作触发,包括配置的连接、打开的网站及其资源、下载与共享。网页本身可能加载广告或跟踪器。

麦克风、摄像头和位置权限为可选权限，仅在你同意网站的请求后使用。权限弹窗会显示网站来源，三项权限可独立配置。已保存的网站可记住决定，临时网页每次询问。
