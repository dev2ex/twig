Adds a 32-bit ARM build. Until now the app shipped for 64-bit ARM and x86_64 only, so older 32-bit devices could not install it. It is published on GitHub as a separate download and is untested on real hardware — the native code it carries (SMB, zstd, the FFmpeg decoder, the terminal's PTY) has only run on 64-bit here.

Per-architecture downloads exist for the other two as well, each about 2.5 MB smaller than the combined APK, which is unchanged and remains the one to take if unsure.
