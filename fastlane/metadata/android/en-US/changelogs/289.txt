Native libraries are now laid out for 16 KB memory pages, which Android 15 and later require: on such a device the loader refuses a 4 KB library outright rather than running it slower, so the terminal would have crashed. Termux's terminal JNI is compiled from source for the same reason, since every published build of it is still 4 KB. The libraries also no longer carry a build id that depends on where they were compiled, so a build of a given release is reproducible from its source.
