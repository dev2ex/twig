Twig is a dual-pane Android file manager that puts every storage source in one tree, built with Kotlin and XML views, without Material or unnecessary dependencies.

<b>One tree, every source</b>

Browse local storage, archives, FTP, SFTP, SMB, WebDAV, S3, restic backups and Jellyfin/Emby in one tree. Copy between sources or compress an SMB folder into a local ZIP. Archives expand in place like folders.

<b>Small and resource-conscious</b>

The 1.16.0 libre APK measures 10.45 MiB for arm64-v8a and x86_64 together, including the terminal and media player. Dependency size is measured before inclusion.

<b>Features</b>

<ul>
<li>Independent panes and root visibility; thumbnails and per-folder sorting/list/grid views, optionally inherited by subfolders</li>
<li>Copy, move and delete with background progress and cancellation; local trash with batch restore/purge; save shared files or text through a dual-pane picker</li>
<li>Batch rename with text/regex replacement, numbering and previews; name dialogs open the keyboard and select names while preserving file extensions</li>
<li>Read/create encrypted ZIP/7z and remember the last format; browse tar and gz/xz/bz2/zst</li>
<li>Folder compare and sync between any two sources</li>
<li>Disk usage treemap with pinch zoom; optional bottom toolbar, Back to exit, completion vibration and foreground notifications</li>
<li>Private space excluded from backups and configuration exports; files are deleted when Twig is uninstalled</li>
<li>Text editing with syntax highlighting and original encoding; hex, PDF, image and media viewers</li>
<li>Music playlists across sources, waveform seeking, synced lyrics, background playback, cover volume gestures and notification timer/exit</li>
<li>Git status, history, side-by-side diff, worktrees and submodules for local and remote repositories</li>
<li>Local, SSH and privileged terminals with multiple sessions, idle dimming and locating the shell directory in the tree</li>
<li>File, folder, website and command shortcuts; editable paths</li>
<li>Wi-Fi sharing: Twig becomes an HTTP and WebDAV server, so a desktop can mount it</li>
<li>Website bookmarks, home-screen shortcuts, per-site display settings, JavaScript/CSS, element hiding, resource blocking and debugging</li>
<li>Website downloads to Downloads/twig; optional background sessions with a service notification</li>
<li>Root/Shizuku access within the local tree; Android/data access through saved SAF grants where Android permits it</li>
<li>Encrypted saved credentials, master-password app lock, fingerprint unlock and configuration backups</li>
</ul>

<b>Less usual things</b>

<ul>
<li>Read-only restic backups decrypted on-device, with snapshots as dated folders.</li>
<li>Videos recognized as one series with at least two episodes share remembered opening/ending skip marks; episode numbers need not be consecutive.</li>
<li>Network MP4/MKV thumbnails fetch keyframes through container indexes, without downloading whole videos.</li>
<li>Blu-ray M2TS playback, including BDAV 192-byte packets, DTS-HD Master Audio, TrueHD through its embedded AC-3 core, and PGS bitmap subtitles.</li>
<li>Jellyfin/Emby playback progress syncs to the server; posters, tags, lyrics and external subtitles come from its API.</li>
</ul>

<b>About this build</b>

F-Droid distributes the free-software <i>libre</i> build without RAR. The developer’s <i>full</i> build adds read-only RAR through junrar, whose UnRAR license has non-free restrictions. Other features are identical.

Twig includes no advertising, no analytics and no telemetry. Network access follows your actions: configured connections, opened websites and their resources, downloads and sharing. Websites may load their own ads or trackers.

Optional microphone, camera and location permissions require your consent for each website and are configured separately. Saved bookmarks can remember decisions; temporary pages always ask.
